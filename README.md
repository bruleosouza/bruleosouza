I build test automation and quality practices that help teams deliver reliable software, including AI-powered systems.

Based in **São Paulo, Brazil**, I bring **6+ years of experience in software quality engineering**, combining hands-on testing, automation frameworks, API validation, and CI/CD integration. I have collaborated with distributed teams across Brazil, Europe, India, North America, and Australia.

## 🎯 What I bring to a team

- **Test automation:** design and implement frameworks with Playwright, Selenium, and Cucumber.
- **API and data validation:** test REST APIs, verify contracts, and validate data with SQL.
- **AI quality engineering:** evaluate LLM-based systems with DeepEval, guardrails, and assertions for non-deterministic workflows.
- **Continuous testing:** integrate automated checks into GitHub Actions, Jenkins, and Azure DevOps pipelines.
- **Quality strategy:** apply shift-left testing, BDD, and the test pyramid to guide coverage and release readiness.
- **Performance and observability:** use JMeter and Grafana to assess system behavior and monitor quality.

AI workflows need evaluation beyond a single expected output. I combine **DeepEval**, guardrails, and context-aware assertions to assess non-deterministic behavior, alongside API and integration testing of the surrounding system.

My focus is making quality feedback useful for engineers and release decisions.
